# Substrate Jetsam's public log

This folder of `uaun/substrate-shared` is the public log of Substrate Jetsam, the opt-in return channel of the Substrate frameworks. An operator chooses to send what their house measured about itself, as enum ids and bucketed counts that carry no one's identity, and the packet lands here, in an append-only log anyone can recount.

Everything in this folder is under the Apache License 2.0, the repository's license: the tools, the schema, the enum files and every packet.

## What a packet can hold

A packet is one framework's digest of one month from one house. Its schema (`schema/1.0.json`) admits exactly four kinds of value: an id from the framework's published enum file (`enums/`), a count from a fixed bucket list (1, 2, 3-4, 5-8, 9-16, 17-32, 33+), a release id, and the month. It has no field that can hold a path, a host name, a time finer than a month, a name, or anything a person wrote, except one optional suggestion, which the sending house scrubbed and the operator confirmed before it left.

A packet carries no install id. A house may turn on a per-month pseudonym, a salted commitment to a secret that never leaves the house, so that its packets in one month count as one house; the link dies when the month ends. Each packet is canonical JSON (RFC 8785) named by the SHA-256 of its bytes.

## Recount it yourself

```
git clone https://github.com/uaun/substrate-shared
cd substrate-shared/jetsam
python3 -I -B tools/verify.py
```

`verify` rebuilds every view from `log/` and compares it, byte for byte, with the views committed here. It also checks that every packet in `log/` is named by its content hash, sits under its framework and month, and appears once in the ledger. It needs Python 3 and nothing else. A difference turns it red. There is no second copy of the data to compare against: this folder is the record.

## Layout

Paths are relative to this folder, `jetsam/`.

```
inbox/                                   packets sent and not yet ingested
inbox/refused/<hash>.json                every refused file, kept so the refusal can be audited
log/<framework>/<month>/<hash>.json      every ingested packet, byte for byte as sent; never edited, never deleted
log/LEDGER.jsonl                         one line per ingest or refusal, with the day, never a finer time
log/TOMBSTONES.jsonl                     one line per withdrawn packet
log/BURN.jsonl                           one line per burned pseudonym-month, with its reason
schema/1.0.json                          the packet schema
enums/<framework>/<release>/enums.yaml   each release's enum file
views/                                   generated by tools/aggregate.py, never edited by hand
tools/                                   ingest, aggregate, verify, tombstone, burn, guard, correlate
tools/jetsam/                            the Jetsam package these tools run, with VENDOR.json naming its commit
                                         and the SHA-256 of every file
```

## The rules

- **Only an automated run writes `log/`.** A packet arrives as a pull request that adds one file under `inbox/`; when it reaches `main`, the ingest workflow (`.github/workflows/jetsam-ingest.yml`) validates it, appends it to `log/`, rebuilds the views, verifies them and commits under the GitHub Actions identity. A pull request that changes `log/`, `views/` or `inbox/refused/` is refused by CI. People change `tools/`, `schema/` and `enums/` by pull request.
- **Every refusal is public.** The ingest refuses a packet that fails any of the validator's 26 checks against the enum file of its release, a duplicate, a second packet from one pseudonym for one framework in one month, and a packet from a burned pseudonym-month. `views/REFUSALS.md` counts them by reason. A log that shows only successes should be distrusted.
- **A view shows a cell only when at least five houses fill it.** A house is a pseudonym-month, or a packet when the pseudonym is off. A cell with fewer reads `suppressed (5)` and is named in `views/SUPPRESSED.md`, so what is withheld is visible. While few houses send, nearly every cell is suppressed; the packets themselves are public in `log/` from the day they land.
- **Nothing is deleted.** A packet is withdrawn by a line in `log/TOMBSTONES.jsonl`, which removes it from every view; the file and the history stay. A pseudonym-month that floods the log is burned by a line in `log/BURN.jsonl` with its reason, and is left out of every view.
- **Anything sent is public, even if refused.** A pull request is public the moment it opens. The sending house validates and scrubs a packet before it can be sent, and asks the operator first.

## Sending a packet

Until a drop point exists, a packet is sent by a pull request that adds its file, unchanged, at `jetsam/inbox/<hash>.json`, from an account the operator chooses. The file is the one the house wrote to its `jetsam/outbox/`.
